# Viewport construction experiment — proposed, not measured

Freeze this plan before its pilot. This is separate from the glyph-memo trial.
The baseline is the implementation left after that trial's keep/remove decision;
the candidate changes only the unnecessary viewport construction in `Context::clip`.
Use the same public-API `scene_index_profile` example for both builds. No new
renderer API, dependency, cache, or representation is needed.

At source commit `9ebac1cba77e77639146b4c86f7b1adfa6574b43`,
`crates/pagura-render/src/compositor.rs:403-434` constructs a viewport Path on
every clip-cache miss, then uses the page crop instead when `soft_source` is
false. The soft-mask source deliberately uses the viewport; preserve that branch
and its geometry (`compositor.rs:1426-1444`). Move construction into the branch
that consumes it; do not substitute viewport geometry for the ordinary crop.

**Source code alone does not prove a heap allocation survives optimization.**
The compiler may already eliminate some or all unused construction. Do not claim
fewer runtime allocations without separate allocation/code-generation evidence,
and do not claim speed from fewer source lines. The paired experiment measures
complete operations, with index/clip setup included. No measurable benefit means
no accepted speed optimization; any later structural-only cleanup is a separate
decision, not a way around these frozen thresholds.

## Fixtures and independent references

All fixtures use 72 DPI, integer geometry, opaque white background and one page.
The independent reference is the geometric intersection of each mark rectangle
with its active clip and the page, authored with the existing PDF/PPM helpers.
It is not generated by either renderer. No font is required.

| Fixture | Geometry and purpose | Independent RGB8 result |
| --- | --- | --- |
| `clip-churn` | 512×512; 64×64 cells of 8×8. Each cell uses a fresh `q`, an inset `(x+2,y+2,4,4) re W n`, an 8×8 black mark at alpha 0.25, then `Q`. Distinct clip identities exercise repeated misses. | 191 inside each disjoint 4×4 intersection, 255 elsewhere. |
| `clip-shared` | Same size/output; install one full-page clip, then paint the inset 4×4 rectangles directly at alpha 0.25. Protect the shared-clip case. | Identical to `clip-churn`. |
| `clip-dense` | 512×512; four 256×256 cells, each with a distinct inset-one-pixel 254×254 clip and a quarter-alpha black mark. About 98.4% painted area; pixel-dominated control, not an all-overlap claim. | 191 inside intersections, 255 elsewhere. |
| `clip-soft-source` | An isolated alpha-mask Form contains the churn geometry, painting opaque white through the per-mark clips over transparent initial state. A black page-sized mark uses that mask. Protect the branch that still needs viewport construction. | 0 inside intersections, 255 elsewhere. |
| `clip-opaque` | Churn geometry with black alpha 1. Protect ordinary opaque behavior, including the Exact opaque path. | 0 inside intersections, 255 elsewhere. |
| `clip-tiny` | 64×64; one 8×8 marked cell and its inset 4×4 clip at alpha 0.25. | 191 inside the intersection, 255 elsewhere. |

Quarter alpha is chosen before this experiment because final nearest RGB8 is
`round(255 × 3/4) = 191`; the earlier half-alpha discrepancy remains recorded
separately and is not hidden by a tolerance. Require exact reference pixels and
opaque output alpha, plus exact baseline/candidate RGBA bytes for each mode.
Preflight the actual generated fixtures before timing; a mismatch blocks the
experiment rather than widening a tolerance. Keep existing soft-mask crop and
transform correctness cases in the subsequent full check; integer mask fixtures
alone cannot prove fractional crop-once semantics.

## Frozen 20-cell matrix

Both Exact and Competitive apply to every entry below:

- `clip-churn`: `full` is the target; `cold`, `tile`, and `tiled` are protected (8 cells).
- `clip-shared`, `clip-dense`, `clip-soft-source`, `clip-opaque`: protected `full` (8 cells).
- `clip-tiny`: protected `full` and `cold` (4 cells).

`full` times one fresh compiled retained-list render. `cold` times document open,
compile and render. File reads/output emission are outside those metrics; this is
warm-filesystem evidence, not cold-I/O evidence. `tile` is the existing top-left
256×256 request, and `tiled` includes complete row-major tile rendering/assembly.
Retain all stage timings, actual commands, diagnostics and output artifacts.

## Sampling and decisions

- Pilot: five measured pairs plus five warmup pairs per cell; order seed 20261022.
  It can reject/defer further work but can never admit the change.
- If worth pursuing, one fresh fixed confirmation: 200 measured pairs plus five
  warmup pairs per cell; order seed 20261023. No pilot pooling or interim results.
  This is 8,000 measured outputs plus 200 warmup outputs. Two hundred pairs do not
  guarantee sufficient p95 precision or bootstrap validity under time dependence.
- Analysis: existing paired percentile bootstrap, 5,000 resamples, one-sided
  95% bounds, statistical seed 42017. Preserve complete pairs and timestamps.
- Both target cells must have median upper bound ≤0.95 and p95 upper bound ≤1.00.
  All 18 protected cells must have both upper bounds ≤1.02. These are per-cell
  estimates, not a simultaneous 95% confidence claim about the whole matrix.
- Every cell must retain valid peak RSS and satisfy max(candidate RSS) /
  max(baseline RSS) ≤1.0. Do not substitute a median, discard outliers, or infer
  zero memory cost merely because the patch removes source-level construction.
- Exact independent pixels, baseline byte parity, unchanged diagnostics where
  applicable, stable source/binary/harness/input identities, complete artifacts,
  a valid environment record, and the serial full check are required.
- A missed upper-bound threshold is non-admission, not automatically proof of
  regression. Unresolved dependence, missing evidence or failed quality checks
  cannot pass. No automatic post-launch restart or second chance after a failed
  gate. Preserve every attempted run and all excluded preflight records.

Run only under the coordinator's exclusive workflow and active contention guard;
no parallel build/test/profile/render jobs. Zero-child refusals may wait for the
authorized quiet period. The opportunity is consumed on benchmark-child launch.
Predeclare a 35-minute maximum launched run and respect any earlier absolute
reservation deadline. Abort on detected contamination; never signal foreign jobs.

Freeze the finalized baseline first, then build baseline and candidate serially
with the identical example/toolchain/flags. Record commits AND source-tree/binary
hashes; a commit identifier alone does not identify an uncommitted implementation.
The Python runner may be minimally factored to share retention/pairing logic, but
that common harness must be frozen before either candidate is measured.
Explicitly hash the imported fixture module and every factored runner module,
as well as the top-level driver and example: the current `source_identity`
does not include arbitrary `benchmarks/*.py`, so `driver_sha256` alone would
leave an imported fixture generator outside the recorded harness identity.

Claims, even on success, concern this native one-thread clipped-rectangle matrix.
They do not establish a competitor, WASM, general-PDF, or world-leading result.
