Historical executable source archive for the exact u16 N16 experiment.

These files are byte-identical copies of the executed local drivers and auditors.
The report binds their original local paths and all receipts. The failed first
RSS audit is preserved beside its platform-string correction. Native benchmark
and independent matrix-audit entry points remain in benchmarks/.

Drivers retain original checkout, binary and evidence paths. Reproduction needs
the pinned baseline/candidate source states, toolchain, generated fixtures and
build bindings; this is not a portable one-command rerun. Raw binaries, images,
logs and samples remain in the local evidence directory, bound by report hashes.
