Every stage counts.

The hybrid path prepares the same scene and produces exact coverage on the CPU. The GPU composites the ordered N16 spans and returns the pixels.

Both paths use the same SIMD WebAssembly engine and warm document state.

Conservative by construction.

Opaque solid fills, strokes, clipped paths and text can use the GPU. Images, dynamic opacity, groups, masks, overprint and F32/F64 buffers keep their CPU renderer.

Local exploratory measurements. A hybrid compositor experiment, with no general GPU rasterization or release performance claim.
